#PROBLEM STATEMENT 
Managing money can be a difficult task for many people. People often forget where they are spending their money and lose track of their expenses. Without a tracking system these tasks can become so much challenging.
A expense tracker can easily tackle these problem. It will include importnat features like money added, expenses, category, remaining balance. It will help people to keep track of their spending and to check their remaining balance.

#Scope of the project
This projects aim on making a expense tracker which helps human to keep track of their spending.
it  allows user to add money , add their expenses , categorise both the source of money and expenses , it also shows them the final balance after deduction of the expenses.
The scope includes:
1. Adding money
2. adding expenses and its category
3. showing transactions
4. checking the final balance
5. providing a simple menu based program

this project is mainly for simple personal expense management.

#Target User
Anyone who has trouble remembering their expenses and in managing their income can use it.
however primary user would most probably be:
1.College students
2.Students staying away from home
3.school students(to learn basics of saving and expenses)

#High level features
this code contains 5 main features:
1. addmoney : it helps the user to enter money to be added along with the category
2. addexpenses: this features allows them to add their expenses along with the category
3. view transactions: this allows user to see the overall history of money added and expenses
4. check balance : this featured shows them their current balance by adding or substracting as per required
5. exit: allows user to end the program onces he is done using it
