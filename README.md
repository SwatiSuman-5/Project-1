EXPENSE TRACKER

A.**Project Overview**
The expense tracker is a simple menu driven program which helps user to keep track of their balance,expenses and transactions.
The program uses simple python codes and menu based layout making it easy for the user to work with.
it allows user to add money to their balance,add expenses and categorize them,see the transactions and view thier remaning balance

B.**FEATURES**
1. addmoney : it helps the user to enter money to be added along with the category
2. addexpenses: this features allows them to add their expenses along with the category
3. view transactions: this allows user to see the overall history of money added and expenses
4. check balance : this featured shows them their current balance by adding or substracting as per required
5. exit: allows user to end the program onces he is done using it
